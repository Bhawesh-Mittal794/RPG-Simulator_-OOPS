# ⚔️ RPG Battle Simulator

A text-based RPG Battle Simulator built using **Python and Object-Oriented Programming (OOP)**. Create your character, choose your class, fight enemies and bosses, collect weapons and potions, and progress through 15 challenging levels.

## 🎮 Features

- **Character Classes:** Choose between Warrior, Mage, and Archer, each with its own characteristics.
- **Turn-Based Combat:** Engage in battles against enemies using your character's abilities.
- **Enemy Progression:** Face increasingly challenging enemies as you advance through levels.
- **Boss Battles:** Encounter powerful bosses at specific levels.
- **Inventory System:** Collect and manage weapons and healing potions.
- **Weapon System:** Equip different weapons to improve your combat capabilities.
- **Level & XP System:** Earn experience points, level up, and improve your character.
- **Loot & Rewards:** Obtain weapons and potions through enemy drops and boss rewards.

## 🛠️ Technologies Used

- **Language:** Python 3
- **Concepts:** Object-Oriented Programming (OOP)
- **Modules:** Python Standard Library (`random`, `copy`)

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your system.

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Bhawesh-Mittal794/RPG-Simulator_-OOPS.git
```

2. Navigate to the project directory:

```bash
cd RPG-Simulator_-OOPS
```

### Run the Game

Execute the `main.py` file:

```bash
python main.py
```

That's it! No additional packages or dependencies are required.

## 🧠 OOP Concepts Implemented

This project demonstrates the practical application of several Object-Oriented Programming concepts:

- **Classes & Objects:** Represent players, enemies, weapons, potions, and other game entities.
- **Inheritance:** Specialized character classes extend the base character class.
- **Encapsulation:** Internal attributes are protected through controlled access and methods.
- **Polymorphism:** Different character classes implement their own combat behaviours.
- **Abstraction:** Game operations are organized into separate classes with clearly defined responsibilities.

## 🎯 Objective

The objective is to survive all 15 levels, defeat increasingly powerful enemies and bosses, upgrade your equipment, and complete the adventure.
